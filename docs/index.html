FAQ

Questions

Windows says “Windows protected your PC”. Is it safe?

FileXp isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info → Run anyway. Only download FileXp from this site or its official GitHub releases page.

Do I need admin rights or .NET installed?

No. The installer installs for your user account only, and includes everything it needs. You can also use the portable zip, which keeps its settings in a Data folder next to the exe.

How do I make FileXp my default file explorer, and undo it?

Open ⋯ → Settings → Make FileXp the default. Folders, drives, Win+E and This PC then open in FileXp. Restore Windows Explorer in the same place undoes it, and uninstalling FileXp does that automatically too.

How does search work without Everything or Windows Search?

FileXp builds its own compact index of every file and folder on your fixed drives, about 84 MB for 1.8 million files. It keeps the index up to date while it runs, and re-scans in the background when the index is older than 6 hours. You can turn it off or rebuild it in Settings.

Does it need 7-Zip?

ZIP works out of the box. If 7-Zip is installed, FileXp uses it automatically for 7z, rar, tar.gz, iso and dozens of other formats.
